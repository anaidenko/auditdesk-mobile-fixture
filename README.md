# Auditdesk mobile fixture

**Deliberately vulnerable. Do not build, ship or reuse this code.**

Two small mobile apps, written to measure how well [Auditdesk](https://github.com/anaidenko/auditdesk)
audits a mobile app: `expo-app/` (Expo and React Native) and `capacitor-app/` (Ionic React and
Capacitor). Each folder is audited as a repository of its own. Their defects were planted on
purpose, and the answer key lives in Auditdesk (`evals/answers/mobile-fixture.yaml`), not here.

The keys and tokens in this repository are made up and work nowhere.
